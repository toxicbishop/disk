# Go File System Simulations

This directory contains three separate Go programs that were previously conflicting. They have been organized into their own directories to prevent redeclaration errors.

## Structure

- **example1/**: Contains the contiguous file system simulation (previously `1.go`).
  - Run with: `go run ./example1`
- **example2/**: Contains the paged file system simulation (previously `2.go`).
  - Run with: `go run ./example2`
- **chunks/**: Contains the simple chunk calculation test (previously `go.go`).
  - Run with: `go run ./chunks`
